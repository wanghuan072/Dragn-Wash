# Drag'n Wash Player Field Manual

[dragnwash.com](https://dragnwash.com) is an independent, player-first companion for **Drag'n Wash**. The game puts you behind the tools of a wash-and-care station for dragons, mixing tactile first-person tasks with conversations, character relationships and a short branching story.

This field manual is built for the questions that appear during an actual run: where to go after answering the phone, which tool the current request expects, why a clean bar will not advance, what changed in a patch, and how to approach another ending without relying on an invented choice chart.

## Common questions

### Is Drag'n Wash free?

No. It is a paid game. Use the verified links in [Stores & Platforms](https://dragnwash.com/#buy) and avoid websites offering an unofficial “free download.”

### How many dragons and endings are there?

The current game centers on Alexander, Ryan and Conrad. The developer lists three endings. Our [Endings](https://dragnwash.com/endings) page does not invent official-sounding “good,” “bad” or “true” labels where the game has not published them.

### How long is a run?

The published estimate is approximately 90 minutes of content per ending. Your time can vary with reading speed, exploration, repeated cleaning checks and replays.

### Why will the wash not finish?

First confirm the current request, then inspect the silhouette from more than one angle, rinse remaining soap and switch tools only when the objective calls for it. The [Wash Progress](https://dragnwash.com/troubleshooting/wash-progress) guide gives a symptom-first decision path.

### Are mods official?

Community localization and VR work are third-party projects. Steam Workshop support has been discussed as a development priority, but a plan is not the same as a shipped feature. Check the [Mods](https://dragnwash.com/mods) page before installing anything.
